## 편집 검토 결과

- 세 대본은 모두 과학 설명과 신화를 구분하며, 단 하나의 정본이라고 주장하지 않습니다.
- 한국어·영어 각 18개의 대응 문장으로 구성되며 주요 인물·사건·질문의 의미가 일치합니다.
- 가족 대화 질문과 감상 안내는 각색에서 더한 내용이며, 원문을 그대로 읽는다고 표시하지 않습니다.
- 최초 초안에서 이야기 중간에 들어갔던 제작 과정 설명과 성인 관계·공포 묘사 생략 안내는 제거하고 출처/각색 안내에만 남겼습니다.
- 검토된 대본의 원문 리비전 정보는 리터럴로 고정되어 있어, 새 원문 수집 결과만으로 기존 각색 대본의 출처가 바뀌지 않습니다.

현재 대본 분량은 공백 포함 한국어 약 795–801자, 영어 261–263단어입니다. 한국어 분당 340자, 영어 분당 145단어를 가정한 추정은 약 2.3–2.4분 / 1.8분이며, 화면에는 추정치로 표시해야 합니다. 기기 음성·속도·쉼에 따라 실제 길이는 달라집니다. 실제 음성 재생 시간을 측정하거나 스피커로 청취한 결과는 아닙니다.

## 출처와 이용 조건

[Wikimedia의 공식 재사용 안내](https://www.mediawiki.org/wiki/Wikimedia_APIs/Content_reuse)에서 제목·저자·출처·라이선스, 수정 여부 표시 및 동일조건변경허락 준수를 확인했습니다. 각색 대본의 출처 표시에는 한국어 위키백과 문서 제목, 기여자/편집 이력, 고정 리비전 링크, 변경 사실, CC BY-SA 4.0 링크가 필요합니다. 해당 조건은 원문 및 각색·번역 텍스트에 대한 안내이며 기존 이미지나 앱 코드의 사용 조건을 대신하지 않습니다.

[공식 API 접근 정책](https://www.mediawiki.org/wiki/Wikimedia_APIs/Access_policy)은 식별 가능한 User-Agent 또는 Api-User-Agent와 호출 제한 준수를 요구합니다. 수집 스크립트는 식별자와 제한된 재시도를 사용하며, 원문 갱신을 각색 대본의 자동 승인으로 취급하지 않습니다.

## 미검증 범위

실제 음성 청취·정확한 재생 시간·자막 타이밍은 이 편집 검토에 포함하지 않았습니다. 브라우저에서의 대본·음성·자막 연결, 출처 링크 동작, 모바일 표시와 저장/다시 보기 동작은 앱 검수 결과에서 별도로 확인해야 합니다. 실제 아동·보호자·보조기술 사용자 검증과 사람의 신화 전문 감수는 미완료입니다.
