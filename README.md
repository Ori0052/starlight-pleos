# STARLIGHT PLEOS — 별빛 드라이브

가족이 주차한 차량에서 천체를 탐색하고 이야기를 듣거나 읽는 서비스입니다. React + TypeScript 웹 프로토타입과 웹 화면·에셋을 번들한 Android 릴리스 앱을 제공합니다. 실제 차량 SDK 제어는 연결하지 않았으며, 차량 조작은 명시된 시연으로 동작합니다. 자료 공유 사이트와 분리한 프로젝트입니다.

공개 저장소: https://github.com/Ori0052/starlight-pleos

## 실행

```sh
git clone https://github.com/Ori0052/starlight-pleos.git
cd starlight-pleos
npm ci
npm run dev -- --port 5173
```

`http://localhost:5173`에 접속합니다. 배포 빌드는 `npm run build`, 결과는 `dist/`입니다. 개발 서버 대신 `npm exec vite preview -- --host 0.0.0.0 --port 4173`으로 빌드 결과를 확인할 수 있습니다.

Node.js 22 LTS와 npm을 사용합니다. `.github/workflows/build.yml`은 GitHub에서 웹 빌드와 Android 릴리스 빌드를 확인하고 결과물을 보관합니다. 실제 실행 결과는 Actions의 해당 커밋에서 확인해야 하며, 워크플로 파일의 존재만으로 성공했다고 주장하지 않습니다.

- 설치·빌드·서명 안내: [Android README](android/README.md)

- 실제 웹 검수·캡처·시연 자료는 `submission/`에서 제공합니다. 개인정보와 동의·서명용 접수양식은 공개 저장소에 넣지 않습니다.

```sh
adb install -r apk/starlight-pleos-release.apk
adb shell am start -n com.starlight.pleos/.MainActivity
```

APK는 사이트를 원격으로 여는 링크가 아니라 `dist/`를 포함한 Android WebView 앱입니다. 기본 UI·그림·검토 대본·로컬 음악을 번들하며, 외부 녹음·일부 음악·지도·출처 링크는 네트워크가 필요합니다. 앱의 로컬 기록과 설정은 데스크톱 브라우저와 동기화되지 않습니다. 별도 프로토타입 릴리스 키로 서명하며 키·비밀번호는 공개하지 않습니다. CI 재빌드는 임시 키를 사용하므로, 제출용 APK는 위 `apk/` 파일과 검증 해시를 기준으로 합니다.

테스트 환경은 웹 Chromium 1920×1080 및 모바일 390×844, Android API 36 일반 AOSP 에뮬레이터입니다. 일반 Android 검증과 Pleos Connect 에뮬레이터 검증은 구분합니다. **실제 Pleos 에뮬레이터 버전·구동과 SDK 연동은 아직 검증하지 않았습니다.** 설치·실행의 구체적인 성공 여부와 환경 값은 네이티브 검증 문서에 실제 결과로 기록합니다.

## 화면과 완주 경로

- `#sky`: 드래그 시연 하늘, 오리온·큰곰·카시오페이아, 동일 선택을 공유하는 목록과 설명.
- `#solar`: 태양 및 8행성의 순서, 전체 모형/목록, 태양과 달의 별도 학습 진입.
- `#detail`: 천체별 이미지·설명·서로 다른 사실, 이전/다음, 이야기·저장·공동 감상.
- `#story`: 한국어 신화 3편의 승인된 Annie 녹음 음성, 실제 오디오 시간 이동, 음량·자막·전체 대본·기록. 영어와 과학 이야기는 기기 음성을 사용합니다.
- `#ceiling`: 원본 파노라마 루프 콘셉트 배경, 천체 전환, 실제 CSS 밝기, 종료 타이머, 일시정지·종료.
- `#vehicle`: 차박 케어·창문·공조·조명·좌석. 하늘·태양계·여행·기록 다음의 다섯 번째 하단 메뉴인 차량에서 진입합니다. 데스크톱 주차 상태와 천장 감상 화면에서도 열 수 있으며, 명시적으로 시연을 시작한 뒤 예시 차량을 조작합니다.
- 설정: 전체 자막 ON / 음성 설명 ON / 큰 글씨 OFF / 모션 줄이기 ON. 각각 독립, 로컬 영속 저장.
- 공동 감상 패널: 대기→연결→모바일 시연 조작→끊김→재연결. 연결이 끊겨도 현재 화면 감상을 이어갑니다.
- `#travel`: 예시 장소, 로컬 장소 저장, 목적지 확인, Google Maps 경로 연결. 위치·날씨·거리 미연결 상태를 명시합니다.
- `#records`: 저장 날짜·분류·완료 상태, 메모 수정, 다시 보기, 삭제 확인, 빈 상태.
- `#design`: 실제 UI 컴포넌트, 토큰, 상태, 기본/큰 글씨·자막 비교. 주요 내비게이션과 분리했습니다.
- `#developer`: 일반 메뉴에 노출하지 않는 차량 상태 시연. 주행 제한·권한 부족·미지원·끊김·오래된 상태, 기능별 지원 여부, 요청 거절·시간 초과를 전환해 대안과 실패 복구를 확인할 수 있습니다.

대표 경로: 하늘에서 별자리 선택 → 자세히 보기 → 이야기/대본 → 읽기 완료 → 기록 → 메모 수정/다시 보기/삭제. 태양계에서는 8행성 전체를 동일하게 선택·상세 탐색할 수 있습니다.

## 실제 동작과 저장 범위

선택 공유, 화면 이동, 대본, 설정, 밝기, 타이머, 기록 CRUD, 언어 전환은 실제 웹 동작입니다. `localStorage`에는 설정·언어·선택·개인 기록·저장한 여행지·차량 화면의 선택 탭과 직접 입력한 컨디션을 저장합니다. 서버로 전송하지 않으며 다른 브라우저·기기와 동기화하지 않습니다. 같은 천체/이야기/분류/날짜의 반복 저장은 같은 기록을 갱신합니다.

차량 환경은 브라우저 메모리의 예시 상태로 동작합니다. 네 창문의 열림·닫힘·멈춤, 앞/뒤 독립 공조, 조명 미리보기, 네 좌석의 위치 도식과 적용값이 실제로 바뀝니다. 요청 대기·실패·취소를 처리하며 적용 전 값과 반영값을 구분합니다. 새로고침하면 예시 차량으로 초기화됩니다. 감상 중 차량 환경을 열어도 천체 선택과 재생을 유지하며, 종료 타이머는 계속 흐릅니다. [차량 환경 구현 범위](docs/VEHICLE_ENVIRONMENT.md)를 참고하세요.

한국어 신화 3편은 사용자가 승인한 HeyGen Annie 음성으로 생성한 녹음을 재생합니다. 실제 HTMLAudio 재생 이벤트·시간으로 진행률과 합성 서비스의 문장별 타임스탬프 자막을 연결합니다. 녹음은 현재 외부 CDN에서 제공하므로 네트워크가 필요합니다. 재생 실패 시 대본과 사용자가 선택하는 기기 음성 대안을 제공합니다. 영어·과학 이야기와 별도의 시각 장면 설명은 Web Speech API를 사용합니다. 음성이 시작되지 않으면 재생 중으로 표시하지 않습니다. 자막을 꺼도 전체 대본은 유지됩니다. Pleos나 OpenAI 음성 SDK 연동이 아닙니다. 생성·확인 범위는 [음성 문서](docs/NARRATION.md)에 기록했습니다.

별자리 이야기에는 드뷔시 「달빛」을, 8개 행성 이야기에는 각기 다른 지정 곡을 낮은 음량으로 반복합니다. 재생·정지 상태에 따라 함께 재생·일시정지하며 켜기/끄기와 별도 음량을 로컬 저장합니다. 천체를 바꾸면 이전 곡을 멈추고 다음 이야기의 재생을 기다립니다. 행성별 음원·디지털 연주·발췌·외부 연결 범위는 [행성 음악 문서](docs/PLANET_MUSIC.md)와 [검수 결과](docs/PLANET_MUSIC_QA.md)에 기록합니다. 음악은 앱에 포함되며 Laurens Goedhart의 2011년 녹음(CC BY 3.0)입니다. 작곡 저작권과 녹음 저작권을 구분한 [음악 출처](docs/MUSIC.md)를 제공합니다.

하늘의 ‘별자리와 문화별 이야기’ 안내는 공식 별자리 88개 / 현재 신화 3편 / 문화별 소개를 구분합니다. 문화별 소개는 기관 자료로 연결하며 모든 문화의 대본을 수록했다는 뜻이 아닙니다. 새 이야기 추가는 보류했습니다. [가이드 범위](docs/STORY_LIBRARY_SCOPE.md)를 참고하세요.

공동 감상은 **같은 브라우저 창 안**에서 차량 영역과 휴대폰 시연 영역을 연결합니다. 선택 ID·이야기 ID·재생 상태·문장 위치를 공유하고 명령 순서를 증가시킵니다. 보조 화면의 자막·큰 글씨·모션 설정은 별도 키로 유지합니다. 외부 휴대폰 연결·실시간 서버 세션·QR 페어링은 구현하지 않았습니다.

## 시연과 추가 연동 필요

현재 하늘은 항상 시연으로 표시합니다. 여러 계절의 별자리를 함께 탐색하는 학습 장면이며, 관측 가능한 하늘·카메라 AR·방향 센서·천문 위치 계산이 아닙니다. 태양계 모형도 실제 크기·거리·실시간 위치와 무관한 학습 모형입니다. 태양은 별, 달은 지구의 위성이며 8행성에 포함하지 않습니다. 지구 상세에 현재 하늘 찾기를 제공하지 않습니다.

차량 상태 기본값은 **주차 감상 시연**입니다. 실차의 주차 상태를 추정하지 않습니다. 개발 패널에서 주행 제한을 선택하면 시각 탐색을 목록으로 바꾸고 천장 감상을 제한합니다. 그 밖의 차량 상태 확인 실패 시 천장 감상을 막고 대본 대안을 제공합니다. 시연은 실제 운전 정책 인증을 대체하지 않습니다.

실제 AAOS/Pleos 연결은 `src/services.ts`와 `src/vehicleControls.ts`의 어댑터 경계에 별도로 구현해야 합니다. 필요 항목은 차량 상태/UX 제한, 위치, 하늘 계산, 날씨, 내비게이션 응답, 차량 음성, 외부 공동 세션과 권한·기능별 지원 여부·실제 값 재조회가 포함된 차량 제어입니다. 현재 창문·공조·조명·좌석·잠금은 웹 시연이며 실제 차량 제어와 천장 투사는 연결하지 않았습니다. 웹 프로토타입의 완성과 Android/Pleos 앱의 실행·SDK 연동 완료는 별도입니다.

2026-11-15 최신 공식 공지 08 확인: 공개 개발 문서의 Vehicle·NaviHelper·TextToSpeech·SpeechToText·FusedLocation SDK는 워크스페이스의 ‘준비 중’ 표시와 별개로 문서에 따라 에뮬레이터에서 개발·시험할 수 있습니다. Gleo Interface도 공모 참가팀에 별도 승인 없이 허용됩니다. 본 앱이 그 SDK를 실제로 연결·검증했다는 뜻은 아닙니다. [차량 SDK 조사](docs/VEHICLE_SDK_REVIEW.md)에 공개 API와 실제 미연동·미검증 범위를 구분했습니다. NaviHelper 요청 성공만으로 경로 완료라고 표시하지 않고 실제 완료/오류 콜백을 처리해야 합니다. 실차 제한은 속도 0이 아니라 AAOS CarUxRestrictionsManager 정책을 구독해야 합니다.

## 디자인·에셋·검수

공유 자료의 발표·기획·디자인 PDF 원본을 Sites 저장소에서 읽어 확인했습니다. 합성 슬라이드를 앱 화면으로 사용하지 않고, PDF 내부의 글자 없는 원본 래스터를 추출해 별도 UI와 사용합니다. 8행성 원본 이미지, 금성 구름 이미지, 차량 천장/실내 배경을 재사용했습니다. 달은 NASA SVS 전체 원반 학습 이미지, 태양은 NASA SDO 자료를 사용합니다. [에셋 출처](docs/ASSETS.md)에 파일·사용 조건·남은 출처 확인 항목을 기록했습니다. Figma 최신 프레임 직접 대조는 제공자 Starter 플랜 호출 한도로 미완료입니다.

[검수 결과](docs/QA.md): 실제 Chromium에서 1920×1080 및 390×844, 한국어/영어·큰 글씨, 키보드, 기록 CRUD, 8행성, 설정 유지, 공동 감상, 종료 타이머를 확인했습니다. OS 모션 감소도 CSS에서 따릅니다. 실제 스피커 음성 청취·실차·스크린리더/장애 당사자 검증은 하지 않았습니다. 보조기술 기능 구현과 검증 완료를 구분합니다.

[차량 환경 검수](docs/VEHICLE_QA.md): 어댑터 상태·취소 검사 15개와 브라우저 흐름 검사 18개를 통과했습니다. KO/EN 큰 글씨의 모바일 5개 탭, 오류·권한·주행 제한, 키보드 조작과 차량 화면 뒤에서의 감상 종료 타이머를 포함합니다. 실제 차량이나 SDK의 동작 검수는 아닙니다.

## 별자리 신화 대본 업데이트

오리온자리·큰곰자리·카시오페이아자리에 `별자리 신화 / 별의 과학` 선택을 추가했습니다. 신화는 MediaWiki Action API에서 문서의 신화 문단을 판본 고정으로 수집한 뒤 한국어·영어 가족용 대본으로 각색했습니다. 1–3분은 읽기 속도 기준의 추정치이며 실제 음성 길이를 측정한 값은 아닙니다.

검토한 대본은 앱 번들에 저장합니다. 화면을 연 뒤 이야기를 바꿀 때 원문 API를 다시 요청하지 않습니다. 초기 앱 로딩까지 완전한 오프라인 실행을 보장하는 서비스 워커는 구현하지 않았습니다. 이야기 제목·대본·자막·브라우저 음성·천장 감상·공동 감상 보조 화면은 같은 대본 데이터를 사용합니다. 신화/과학 종류를 바꾸면 기존 음성을 취소하고 새 대본의 첫 문장부터 시작합니다.

감상 기록은 신화와 과학의 이야기 ID를 구분해 저장하고, 다시 보기에서 해당 종류를 복원합니다. 기존 과학 이야기 기록도 유지됩니다. 대본 아래에 원문·기여자 이력·사용한 판본·각색 여부·CC BY-SA 4.0 이용 조건을 표시합니다. 각색 대본의 라이선스와 앱 코드·이미지의 라이선스는 구분합니다.

원문 갱신은 `npm run content:fetch`로 검토 후보를 수집한 뒤 출처·대본을 대조하는 개발 작업입니다. 외부 문서 변경을 재생 대본에 자동 반영하지 않습니다. 구현 당시 이 실행 환경의 직접 HTTP 요청은 프록시에서 거부되어, 실제 공개 Action API 응답은 제공된 웹 조회 경로로 수집했습니다. 갱신 스크립트의 실제 네트워크 성공과 앱의 저장 대본 이용을 구분합니다.

자세한 원문 판본·각색·검토 방법은 [신화 콘텐츠 문서](docs/MYTHOLOGY.md), [독립 내용 검토](docs/MYTHOLOGY_REVIEW.md), [화면·음성 연계 검사](docs/MYTHOLOGY_QA.md)에 기록합니다.
